# Letter

Letter is a Ruby on Rails application for a letter protocol server.

## Requirements

- Ruby 3.4.9
- Bundler 2.6 or newer
- SQLite 3

## Getting started

```sh
bin/setup
bin/rails server
```

Open <http://localhost:3000> to view the application. The health check is
available at <http://localhost:3000/up>.

## Tests

```sh
bin/rails test
```
